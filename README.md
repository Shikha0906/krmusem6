## 📖 Project Description
The **Weather Website** is a web-based application that provides real-time weather information for any city in the world.  
It displays current temperature, humidity, wind speed, and weather conditions using live weather data fetched from a public API.

---

## 🎯 Objectives
- To display real-time weather data  
- To allow users to search weather by city name  
- To understand API integration in web development  
- To create a responsive and user-friendly interface  

---

## ⚙️ Features
- Search weather by city name  
- Real-time temperature and weather conditions  
- Humidity and wind speed details  
- Dynamic weather icons  
- Responsive design for mobile and desktop  

---

## 🛠️ Technologies Used
- **Frontend:** HTML, CSS, JavaScript  
- **API:** OpenWeatherMap API  
- **Tools:** VS Code, GitHub  

---

## 🧠 Working Methodology
1. User enters the city name  
2. Application sends a request to the Weather API  
3. API returns real-time weather data  
4. Data is processed using JavaScript  
5. Weather details are displayed on the webpage
